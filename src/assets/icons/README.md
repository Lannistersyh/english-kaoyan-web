# Browser icons

The unmodified 16px and 32px NCBI favicons match the grey and blue arrow used by PubMed browser tabs. They are served locally and bundled with hashed URLs by Vite.

Source: https://pmc.ncbi.nlm.nih.gov/articles/PMC11446842/

Original files:

- https://cdn.ncbi.nlm.nih.gov/pmc/pd-medc-pmc-cloudpmc-viewer/production/9b1d9d87/var/data/static/img/favicons/favicon-16x16.png
- https://cdn.ncbi.nlm.nih.gov/pmc/pd-medc-pmc-cloudpmc-viewer/production/9b1d9d87/var/data/static/img/favicons/favicon-32x32.png

The icons identify a personal study replica; the footer and site information disclose the site's purpose.
