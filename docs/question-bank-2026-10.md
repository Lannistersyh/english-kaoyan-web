## Original mocks: 16 sets

All passages and questions in this collection are original teaching material. Scenarios are fictional and should not be treated as published research, medical guidance, or actual past exam passages.

- **8 reading passages:** libraries and public resources; replication; repairable products; communicating uncertainty; citizen science; flood planning; publication incentives; city sound measurement. Each passage has 300–450 words, five questions, explanations for every option, four structure annotations, and vocabulary notes.
- **3 cloze passages:** digital archives, connecting bus services, and project handovers. Each has 20 blanks, four options per blank, contextual explanations, and a total of 10 points.
- **3 new question type exercises:** seven-choose-five oral-history passage, heading matching on evaluating claims, and paragraph ordering about testing public signs. Each exercise totals 10 points. Ordering uses one whole-sequence judgment.
- **2 English paraphrasing tasks:** concession and measurement; a necessary condition with limited scope. Both include original reference paraphrases and three-step structural guidance.

Open **Practice** and search **October 2026** for the 14 new objective sets. Use **Paraphrasing** for the two new subjective exercises and filter **Source** to **Original mock · October 2026**.

## Compatibility and cost

New source metadata and word targets are optional. Legacy imported questions and backups remain valid. New short writing tasks display an approximately 100-word target, while existing picture essays retain their 160–200-word label. Cloze totals are calculated from the actual exercise.

Adding or using these questions does not call a paid AI service. Reference answers, explanations, objective grading, and self-assessment work without an API key.
